# AmrutamSuperApp

An Ayurvedic Super App built with React Native (Expo 57), TypeScript, and React Navigation.

## Modules

- **Consultation** – Browse doctors, book time slots, manage upcoming & past consultations
- **Shop** – Ayurvedic product catalog with cart, wishlist, and checkout
- **Health Records** – Patient medical timeline with categories and attachment preview

## Tech Stack

- Expo SDK 57 / React Native 0.86 / React 19
- React Navigation 7 (Stack + Bottom Tabs)
- TanStack Query v5 (server state)
- Zustand v5 (client state)
- MMKV (fast local storage)
- Unistyles v3 (Light/Dark theming)
- i18next (EN/HI localization)
- Yarn

## Getting Started

```bash
yarn install
yarn start
```
